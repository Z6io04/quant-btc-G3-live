# G3 真钱交易程序与自动代理切换工具

G3 使用独立欧易子账户，买入 **BTC-USDT 现货**，做空 **BTC-USD-SWAP 币本位永续**，账户设置为全仓 2 倍。空仓且允许新增交易时，每个新完成的分钟重新评估入场；满足条件后仍等待一分钟并重新核对。恢复联网后可以重新寻找机会，过期且未提交的入场计划不会补下单。

这是可上传 GitHub 的源码交付包，包含已修复的代理看守、首次安装辅助工具和中文配置流程。`launch.py` 与 `g3core/` 保持原 G3 核心内容；没有把密钥、订阅、服务器账本或生产配置打进包里。收益、费用和回测限制见 [F3/G3 比较报告](reports/REPORT.md)，历史比较使用 25U，**程序没有固定 20U、25U 或 30U 本金上限**。

## 程序和代理的关系

```text
G3 → config.json 中的 http://127.0.0.1:17890 → Mihomo → 节点 → OKX
                                               ↑
                                    代理看守检查并在获准后切换
```

`127.0.0.1` 是**运行 G3 的服务器自身**。Mac 的代理设置不会替服务器配置代理。G3 明确读取 `config.json`，不读取 `.env` 或 shell 的代理环境变量。代理节点变化但本机入口仍为 17890 时，无需修改 G3 配置；同用该入口的其他策略也会受到切换影响。

代理看守不持有交易 API、不修改欧易白名单、不下单。当前线路 `check` 只检查 17890；候选探测用独立 17891，不接管生产入口。自动切换还需要明确填写允许出口并启用看守。公网 IP 查询服务看到的出口可能与 OKX 不同，尤其是 IPv4/IPv6 分流时；仍须在欧易手动核实真实出口白名单，并由 G3 单独读取账户核对。

## 哪一步会下单

| 操作 | 作用 |
|---|---|
| `check`、`account-check`、`status` | 只读检查，不下单；账户读取通过不等于交易权限已被实单验证 |
| `setup-config`、`setup-credentials` | 写本地首次配置；只用于未初始化安装 |
| `arm-live` | 明确确认后登记账户、代码/参数和账本，本命令不下单 |
| `deploy/install-service.sh` | 只安装 G3 用户服务，不启动、不启用、不下单 |
| 成功启用后的 `run` 或 `systemctl --user enable --now btc-G3-live.service` | 启动具有真实下单权限的循环 |
| `flatten` | 排队请求真实退出组合，需要确认和运行中的服务处理 |

原有单组损失 3%、账户回撤 5%及用户填写的累计亏损金额条件继续生效。金额限额是额外停止条件，**不是保证最大损失**；网络中断、滑点、两腿不同步或交易所异常可能阻碍退出。本版没有交易所托管的整组两腿止损。充值须空仓停服后手动 `sync-capital`，不会自动提高亏损金额限额。

GitHub 保存源码；真正运行仍在你自己的 Debian 服务器。源码 zip 不包含历史行情大文件，复跑回测另需同批交付的 `G3-backtest-data.zip`，按回测文档放置。
